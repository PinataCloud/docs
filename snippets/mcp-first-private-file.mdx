Paste this prompt into your connected assistant:

```text
Upload a private file called hello-pinata.txt containing only "Hello from Pinata". Give me a download link that expires in 10 minutes.
```

Open the link and check that the file contains `Hello from Pinata`. Anyone with the link can read the file until the link expires. The file stays private in your workspace afterward.

If the upload succeeds but your workspace has no gateway, create one under **Gateways** in the Pinata app. Then ask for a new link to the file you just uploaded; you don't need to upload it again.
