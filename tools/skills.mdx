[Agent Skills](https://agentskills.io) are folders of instructions that coding agents load when a task needs them. The **`pinata`** skill teaches an agent how to use Pinata correctly: the `pinata` SDK, the REST API and the [MCP server](/tools/mcp/overview), public and private files, presigned uploads from the browser, groups, gateways and access links.

Install it into your project:

```bash
npx skills add PinataCloud/skills
```

The [`skills`](https://github.com/vercel-labs/skills) CLI (Node.js 22.20 or later) finds the coding agents you use and installs the skill for each. It supports Claude Code, Codex, Cursor, OpenCode, Gemini CLI, GitHub Copilot, Windsurf and many more. The source is [PinataCloud/skills](https://github.com/PinataCloud/skills).

## Install options

```bash
# Every project on this machine
npx skills add PinataCloud/skills -g

# Only for some agents
npx skills add PinataCloud/skills -a claude-code -a codex

# Without prompts (CI, scripts)
npx skills add PinataCloud/skills --skill pinata -y
```

Skills install into the project by default: `.agents/skills/pinata`, plus a link in each agent's own folder (for example `.claude/skills/pinata`). Commit them so everyone working on the project gets the same instructions. `skills-lock.json` records the version installed.

## What the agent learns

- **Which interface to use:** Pinata's MCP tools when they're connected, the `pinata` SDK for JavaScript and TypeScript, and the REST API for any other language.
- **Public vs private:** what each network means, why to ask before making content public, and which identifier to use where (the file `id` for updates and deletes, the `cid` for serving).
- **Uploads:** files, JSON and folders; presigned upload URLs so browser and mobile uploads never see your API key; resumable uploads for large files; folder limits; key-values and groups.
- **Serving content:** gateway URLs for public files, expiring access links for private files, image optimization, and gateways with [access controls](/gateways/gateway-access-controls).
- **Safety:** keep `PINATA_JWT` on the server, confirm before deleting or publishing, and treat file names and fetched content as data rather than instructions.
- **Troubleshooting:** what common errors mean, such as a `404` from the wrong network, a gateway `401 ERR_ID:00024`, or a presigned folder upload refused for its MIME type.

## Use it

Agents load the skill on their own when a task involves Pinata, IPFS or `*.mypinata.cloud`. You can also name it:

> Use the pinata skill to add avatar uploads to this Next.js app: the browser uploads with a presigned URL and the profile stores the CID

> Using the pinata skill, write a Python script that uploads ./dist as one public folder and prints its gateway URL

To try it without installing:

```bash
npx skills use PinataCloud/skills@pinata --agent claude-code
```

## Plugins

The plugins bundle the `pinata` skill with the [hosted MCP server](/tools/mcp/hosted), so the agent can also upload, share and manage files on your account.

| Agent | Install | Connects with |
|---|---|---|
| Claude Code | `claude plugin install pinata --marketplace PinataCloud/skills` | Your Pinata account: sign in when Claude asks, or from `/mcp` → **pinata** → **Authenticate** |
| Gemini CLI | `gemini extensions install https://github.com/PinataCloud/skills` | Your Pinata account: run `/mcp auth pinata` in a Gemini CLI session |
| Codex | `codex plugin marketplace add PinataCloud/skills`, then `codex plugin add pinata@pinata` | An [API key](/account-management/api-keys) read from `PINATA_JWT`, exported before Codex starts |

When you sign in, you choose the workspace to connect, and Pinata creates an API key named `MCP OAuth · <client>` for the connection. [Sign in or use an API key](/tools/mcp/hosted#sign-in-or-use-an-api-key) explains what it can do and how to disconnect. For setup and a first private upload, [choose your assistant](/tools/mcp/hosted#connect-your-assistant).

Update the plugins with `claude plugin update pinata@pinata`, `gemini extensions update pinata` or `codex plugin marketplace upgrade pinata`.

## Skills, MCP and LLM docs

| | Gives the agent | Use it when |
|---|---|---|
| **Agent Skills** | Know-how: patterns, rules and pitfalls for building with Pinata | The agent writes code that uses Pinata |
| **[MCP server](/tools/mcp/overview)** | Tools that act on your Pinata account | The agent should upload, search or manage your files directly |
| **[LLM Docs](/llm-docs)** | The full documentation as text | The agent needs the complete reference |

They work well together: the skill tells the agent to use the MCP tools whenever they're connected.

## Update or remove

```bash
npx skills check           # see whether updates are available
npx skills update pinata
npx skills remove pinata
```
